# 📈 Stock Screener - Advanced Financial Dashboard

A **high-performance**, **modern** stock screening application built with **Next.js 14**, **React**, **TanStack Table**, and **Lightweight Charts**. Perfect for tracking and analyzing Indian stocks in real-time.

![Stock Screener](https://img.shields.io/badge/Next.js-14-black?style=for-the-badge&logo=next.js) ![React](https://img.shields.io/badge/React-18-blue?style=for-the-badge&logo=react) ![TypeScript](https://img.shields.io/badge/TypeScript-5-blue?style=for-the-badge&logo=typescript) ![Tailwind CSS](https://img.shields.io/badge/Tailwind-4-blue?style=for-the-badge&logo=tailwindcss)

---

## ✨ Features

### 🎯 Core Features
- **📊 Real-time Data Grid** - View 5000+ stocks with virtual scrolling for blazing-fast performance
- **🔍 Advanced Search** - Search by symbol or company name with instant filtering
- **🏷️ Multi-Sector Filtering** - Filter stocks by IT, Banking, Pharma, FMCG, Auto, Energy sectors
- **💰 Market Cap Filter** - Adjust minimum market cap threshold with interactive slider
- **📈 Interactive Charts** - Candlestick charts with professional styling
- **⚡ Sorting** - Click column headers to sort by any metric
- **📊 Market Dashboard** - Real-time market statistics and insights

### 📊 Stock Metrics Displayed
- **Symbol & Company Name** - Unique identifier and full company name
- **Current Price** - Real-time stock price in INR
- **Change %** - Percentage change with visual indicators
- **P/E Ratio** - Price-to-Earnings valuation metric
- **Market Cap** - Total market capitalization in Crores
- **Trading Volume** - Number of shares traded

### 🎨 UI/UX Excellence
- **Dark Theme Dashboard** - Professional modern interface with gradient backgrounds
- **Responsive Design** - Works on desktop, tablet, and mobile
- **Virtual Scrolling** - Handles 5000+ rows without performance lag
- **Smooth Animations** - Professional transitions and effects
